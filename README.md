
# ⚽ Football Ticket Booking System

A database design and SQL assignment project for managing football fans, matches, and ticket bookings.

##  Overview

This project implements a **Football Ticket Booking System** with:
- Entity Relationship Diagram (ERD)
- PostgreSQL schema design
- SQL queries covering JOINs, subqueries, aggregations, NULL handling, and pagination

## 🗂️ Tables

| Table | Description |
|-------|-------------|
| `Users` | Stores fans and ticket managers |
| `Matches` | Stores football match details and ticket pricing |
| `Bookings` | Tracks individual ticket purchases |
